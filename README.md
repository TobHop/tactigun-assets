# Tactigun! Assets
Basically a bunch of music, spritework, old builds, hence the name Tactigun assets.

If you want the repository locally, you can use [git](https://git-scm.com/downloads) to clone it with:

`git clone https://github.com/TobHop/tactigun-assets.git`

You can update the repository by doing:

`git pull https://github.com/TobHop/tactigun-assets.git`
(Make sure you have initilized git with `git init`)
